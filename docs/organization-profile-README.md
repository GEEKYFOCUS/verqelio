# Verqelio

We build tools that help people and organizations issue, hold, share, and verify portable digital credentials.

Verqelio combines wallet-controlled identity, verifiable credentials, and Stellar infrastructure to make credential data easier to carry and check across services. Our current work includes a credential product, developer SDKs, DID resolution, and Soroban smart contracts.

## What we're working on

- **Portable credentials:** credential workflows designed to work across applications.
- **User-controlled identity:** Stellar wallet-based identity and signing.
- **Open developer tools:** TypeScript SDKs, APIs, and integration examples.
- **Verifiable infrastructure:** DID registry and credential-vault smart contracts.

## Repositories

Explore our repositories for the product application, SDKs, APIs, specifications, and contract implementations. Each project README explains its scope, setup, current limitations, and contribution workflow.

## Principles

- Keep users in control of their signing keys.
- Make interfaces and integration guidance clear to developers.
- Be explicit about what is on-chain, off-chain, simulated, or still in progress.
- Build with privacy and responsible handling of credential data in mind.

## Status

Verqelio is actively evolving. The current application supports testnet and demonstration workflows; some transaction paths and infrastructure still require implementation and review before production use. Check each repository's status and deployment notes before relying on it for real credentials or funds.

## Get involved

Browse the repositories, open an issue to report a problem or propose an improvement, and follow each project's contribution and security guidance. Please do not include private keys, API tokens, personal credential data, or other secrets in issues or pull requests.
