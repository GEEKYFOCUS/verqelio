# Security Policy

The Soroban contracts can control credential integrity and interact with assets on Stellar. Report suspected vulnerabilities privately; do not publish exploit details or test against mainnet.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/GEEKYFOCUS/verqelio/security/advisories/new) for this repository. Include the affected contract and version, network, reproduction steps or a test case, and the potential impact. Do not include private keys, secrets, or personal credential data.

If private vulnerability reporting is unavailable, contact the repository maintainers privately before disclosing details publicly.

## Scope

Reports concerning authorization, credential issuance or revocation, DID control, fee handling, vault ownership, data integrity, or key exposure are in scope. Please identify whether the issue affects a deployed contract, the off-chain API, or an SDK.

This policy does not promise a response or remediation timeline. Maintainers will assess reports based on severity, affected deployments, and available mitigations.
